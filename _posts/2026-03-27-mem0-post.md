Mem0 开源产品的解读

主要产品有:

1. Mem0:更像是整个 memory stack / product family：有托管平台、开源方案、API、graph memory、rerankers、企业功能，目标是给 AI agents/app 提供完整的持久化记忆层。

2. OpenMemory 是 Mem0 生态里的一个更偏 local-first / personal memory infrastructure 的产品，强调“把你的记忆带到任意 AI app”，支持本地运行、MCP 客户端接入，以及更强的个人可控性。官方直接写的是 “OpenMemory is a local memory infrastructure powered by Mem0.”

可以给我研究下目前update会顶掉原来的存储的信息吗，比如我之前说我喜欢吃冰淇淋，但是最近换成了不喜欢吃了因为天气冷了，他会记住吗？

解决的场景是：mem0不能回答你之前的历史喜好

Preference-Aware Memory Update for Long-Term LLM Agents (arXiv:2510.09720, 2025)
这篇论文几乎完美匹配你的场景：针对用户偏好（preferences）随时间演化（如口味、习惯变化），提出Preference-Aware Memory Update Mechanism (PAMU)。它使用滑动窗口平均 + 指数移动平均来融合短期波动和长期趋势，避免简单粗暴的覆盖。实验在LoCoMo数据集上验证，能更好地处理“新信息更新旧偏好”而不完全丢失上下文。
核心：现有记忆更新机制往往不足以动态精炼偏好表示，这篇专门填补了这个gap。
